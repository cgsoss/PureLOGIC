게임 방법

휴대폰: 기본은 수동 모드이며 위 칸 열기/깃발 놓기 버튼으로 동작을 선택합니다. 자동 모드를 선택하면 열린 숫자 칸을 터치할 때 칸 열기 모드, 깃발 칸을 터치할 때 깃발 놓기 모드로 전환됩니다. 깃발을 두 번 빠르게 터치하면 제거됩니다. 위쪽 버튼도 사용할 수 있습니다. 빈 칸을 0.5초 길게 누르면 깃발을 놓습니다. 깃발을 빠르게 두 번 터치하면 깃발이 바로 제거됩니다. PC: 왼쪽 클릭은 선택한 동작, 오른쪽 클릭은 깃발입니다. 자동으로 열리는 시작 칸과 주변 8칸은 안전합니다. 숫자는 주변 8칸의 지뢰 개수입니다. 모든 안전한 칸을 열고 실제 지뢰에 깃발을 모두 정확히 표시하면 승리합니다.
